# astrbot_plugin_agent_progress

在聊天会话中实时查看 Agent 执行进度的 AstrBot 插件。

## 背景

Agent 处理长任务时，用户通常只能等到最终结果才知道过程如何。本插件把执行过程中的关键节点
实时推送到触发任务的会话，使执行过程可见。

## 依赖

需要启用 AstrBot 的 trace 功能（`trace_enable = true`）。插件通过 AstrBot 内部的日志广播器
获取 trace 事件，未开启时不会收到任何事件。

## 工作原理

1. 订阅 AstrBot 内部的日志广播器。
2. 过滤出 `type` 为 `trace` 的事件，按 `span_id` 归并为一次任务。
3. 识别关键动作：`astr_agent_prepare`（任务开始）、`agent_tool_call`（调用工具）、
   `astr_agent_complete`（任务结束）。
4. 依据阈值与间隔做限频，把文本投递回原会话。
5. 插件不调用大模型，不产生模型开销。

## 播报规则

- 任务耗时未超过 `start_after` 时不播报，短回复不受打扰。
- 超过阈值后，两次播报的间隔不小于 `interval`。
- 任务结束时，若过程中播报过，补发一条包含步数与总耗时的汇总。

## 配置

| 配置项 | 类型 | 默认值 | 说明 |
| --- | --- | --- | --- |
| `target_session` | string | 空 | 只播报包含该子串的会话，留空表示全部 |
| `start_after` | int | `30` | 耗时超过该秒数才开始播报 |
| `interval` | int | `30` | 两条播报之间的最小间隔（秒） |

## 输出示例

```
进度：已执行 12 步，当前在做「执行命令」，累计 2 分 10 秒
完成：一共 18 步，用时 3 分 05 秒
```

## 安装

将本插件目录放入 AstrBot 的 `data/plugins/`，然后在管理面板中重载插件。

## 注意事项

- 仅覆盖 AstrBot 自身的 Agent 任务，不监控外部进程。
- 进度以工具调用为最小单位。单次调用内部耗时较长时，两次播报之间不会产生新消息。
- 消息回发到触发任务的会话，不支持指定其他目标。
- 关闭方式：停用插件，或将 `start_after` 设为极大值。
- trace 事件包含会话标识与消息摘要，属于敏感信息，请勿将事件流外发。

## 兼容性

支持 AstrBot v4.x，已在 aiocqhttp 平台验证。
